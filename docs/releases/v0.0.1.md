Première version : les fondations de l'application.

## Nouveautés
- Navigation par onglets : Recettes, Planning, Courses, Réglages (contenu à venir)
- Mise en page adaptée : barre du bas sur téléphone, menu latéral sur tablette
- Thème clair, sombre ou automatique, aux couleurs de la palette
- Icône provisoire
- En cas de problème au démarrage, un écran d'erreur s'affiche (avec un bouton pour copier le détail) au lieu de rester bloqué sur l'icône

## Corrections
- Thème sombre : l'icône de l'onglet sélectionné était invisible sur le fond jaune
- Réglages : le choix du thème est une liste déroulante (le texte ne se coupe plus sur téléphone)
- Réglages : retrait de l'étiquette « Version de test », inutile
- L'application restait bloquée sur l'icône au lancement : l'optimiseur de code (R8) supprimait une méthode du module de préférences appelée au démarrage. Chaque APK est désormais lancé sur un émulateur avant d'être publié.
