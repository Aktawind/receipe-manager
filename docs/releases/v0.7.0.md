Cuisiner sans toucher son téléphone toutes les deux minutes : le mode cuisine.

## Nouveautés
- **Mode cuisine** : un bouton en bas à droite de la fiche
- L'écran reste allumé tant que le mode cuisine est ouvert
- Ingrédients et préparation en grand : deux onglets sur le téléphone, côte à côte sur la tablette
- Les quantités suivent le nombre de personnes choisi sur la fiche
